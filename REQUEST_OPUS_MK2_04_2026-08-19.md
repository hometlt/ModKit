# REQUEST OPUS-MK2-04 — `write`/`edit` onto the 13D seam: converter mapping and the first write ports

Root: Fable. Date: 2026-08-19. Basis: ADR-HOST-002 (`docs/MK3/adr/ADR-HOST-002-binary-editing-on-the-13d-seam.md`,
Accepted; S8 landed in `0910951`), `REPORT_MK2_CONVERSION_2026-08-19.md` §12.2. Sequencing: after
MK2-03. Everything below runs on landed code; nothing waits for Root.

## What S8 gives you (do not re-implement)

- `common.edit/writer@1` is a standard contract: host definition + matcher (facet: `formatId`,
  `representationId`, `mutationMode`, `minimumRoundTrip`), standard surface, resolvable through
  `createHostServiceResolver`, leased worker-brokered; writer providers request **no** permission
  classes (the host commits under `write-source`).
- Codec operations may declare `mutatesSource: true` with the shared verbs (`edit.content`,
  `edit.structure`, `edit.field`, `edit.undo-redo`, `source.save`, `source.save-as`) and return
  `{ kind: 'edit-plan', plan }`; the variant must request `write-source`; a grant without it still
  opens the codec (degraded) and the host refuses the operation at dispatch.
- codec-kit: `editPlanFromInput(input, { planId, edits, fidelity })`, `replaceBytes(offset, length,
bytes)`, `defineWriter({...})` (export `abiVersion`/`provides`/`createProvider` from its result),
  `input` in the inspection context; the PNG `edit.field` in `extensions/common/images` is the
  reference implementation of Path A; `packages/host/test/fixtures/writer-extension` of Path B.
- Host side for proofs: `createSubjectEditing` + `createFileEditingBackend` (host/node); the
  acceptance harness can open → invoke → plan → prepare → commit → reopen exactly as
  `packages/host/test/subject-editing.test.ts` does.

## Deliverables

1. **Converter vocabulary** (`scripts/lib/mk3-vocabulary.mjs`): `write` and `edit` stop being
   `blocked`. `write` → home `writer-provider`: the converter emits, next to the read codec, a
   `service-provider-contribution` `<codec-id>-writer` providing `common.edit/writer@1` with facet
   `{ providerId, fidelityEvidenceId: '<id>-writer-v1', formatId, representationId: 'source',
mutationMode: 'mutate', minimumRoundTrip }` (`minimumRoundTrip` from the v1 fidelity claim when
   present, else `semantic`), one portable variant (`node-worker`, `browser-worker`),
   `requestedPermissionClasses: []`, entrypoint `src/<id>/writer.js` — a `defineWriter` stub whose
   `planEdits` throws `not ported` until a human ports it (the stub is generated; the port is
   hand-written; the `src/<id>/` ownership rule from MK2-03 covers it). `edit` → home
   `codec-operations`: the codec manifest gains the shared-verb operations the v1 `edit` kind maps
   to (`edit.field` for field/value edits, `edit.structure` for add/remove of parts, `edit.content`
   for free-form content), `mutatesSource: true`, `requiredPermissions: ['read-source',
'write-source']`, `outputKinds: ['edit-plan']`, and every variant requests `write-source`.
   Record both in `MK2-CONVERSION.json` (`writer`, `editOperations`) and the generated README.
2. **Verdicts recomputed**: the 33 `write` / 12 `edit` codecs leave `needs new contract` wherever
   nothing else blocks them; the tree is regenerated byte-stable; `convert:mk2 --check` clean;
   `REPORT` counters updated (how many moved, what still blocks the rest).
3. **First write ports (≥ 4)** on the synthetic corpus from MK2-02 — `gzip` (header fields: mtime,
   filename/comment as byte-range edits; recompute nothing that is not touched), `tar` (add /
   delete an entry: whole-source rewrite with untouched blocks copied verbatim), `bmp` and `gif`
   (header/metadata fields as byte-range edits; pixel encoders are out of scope unless trivial).
   Each port: Path A operation(s) on the codec **or** a Path B writer, chosen by what the v1 code
   did; a proof in the harness: open → edit → commit through `createFileEditingBackend` → reopen
   shows the change, every untouched byte identical, refusal without `write-source`; fidelity claim
   honest (`byte-identical` only when untouched bytes are provably untouched).
4. Report + `IMPLEMENTATION_NOTES.md` entry; owner items if a format needs something the seam
   lacks (staged payloads for large rewrites, bundle topologies).

## Rules

`packages/testkit/scripts/**`, `packages/testkit/test/fixtures/mk2-synthetic/**`,

never a key. `pnpm check` green; commit when green (Root reviews).
