`propose`**, а не пишет мусор на диск.

### 1.3 Подключение расширений

- **Статически (`import`)** — `@modkitx-x3/extensions/<id>` и наборы `imagesOnly`, `modelsOnly`,
  `media`, `structuredText`, `archivesOnly`, `documentsOnly`, `everything`. Импорт и есть решение о
  доверии; линкуется только то, что само декларирует `trusted-in-process`.
- **Динамически** — папки пользователя: Electron (живьём), PWA (File System Access, дайджесты
  считает страница, worker-only), VS Code (workspace + настройка), Node-фасад.
- **Отключение расширений и кодеков** — страницы настроек в Electron и VS Code; кодек выключается
  на уровне инвентаря (`disabledContributions`), запись остаётся видимой, а неоткрывшийся файл
  называет причину: `x3.host/candidate-suppressed` вместо молчания.

### 1.4 Способы использования

- **Node-библиотека** — `createModkit({ modules, extensions, roots, writableRoots })`.
- **Веб-компонент** — `<modkit-viewer src=…>`; контракт встраивания (CSP, origin, Shadow DOM)
  измерен в Chromium, не предположен.
- **Минимальная сборка** — субпути на каждую поверхность, `sideEffects: false`, и гейт
  `scripts/test/minimal-build.test.ts` из пяти эталонных конфигураций.

## 2. Что осталось — по приоритету

### Этап 1. Паритет редактирования

1. **Мутирующие операции в VS Code** — единственный хост без них. Швы готовы: арм S14 уже ходит
   через JSON-транспорт, таблицы форм есть в двух вариантах для образца.
2. **Панель байтов записи архива в VS Code** — до паритета просмотра.
3. **Живой круг MP3 в PWA** — нужен отгружаемый образец.

### Этап 2. Сохранение изображений

4. **Пиксельное редактирование PNG** — писатель-энкодер существует и коммитит (Path B), редактор
   изображений честно read-only, потому что рендерер не должен перекодировать пиксели сам. Нужно
   провести writer по фасету `png/rgba8@semantic` до редактора изображений.

### Этап 3. Архитектурные долги, названные агентами

5. **Байты записи архива как хост-задача** — сейчас оба приложения читают запись через
   codec-specific операцию извлечения, потому что `openEntry` возвращает ссылку, которую нечем
   открыть. Нужен стандартный id операции либо переоткрытие вложенного источника хостом.
6. **Кодек публикует свои координаты доказательства.** Записи fidelity перепечатаны в двух
   приложениях, и это **цена границы**: платформенный пакет не вправе знать про zip — гейт границ
   поймал меня на попытке централизовать их там. Настоящий ответ: координаты приходят из инвентаря.
7. **`createSettingsUi` без точки расширения** — поэтому в Electron две страницы настроек вместо
   одной с четырьмя группами. Нужна опция `extraGroups`.
8. **VS Code: полный `CustomEditorProvider`** — родной индикатор изменений и Ctrl+S.

### Этап 4. Оптимизации сборки (не дефекты)

9. PWA на субпути вместо корневого импорта `ui`; webview VS Code — только реально включённые сцены.

## 3. Честные ограничения

- **Видео не редактируется** — писателя нет, и притворяться нечем.
- **VS Code не запускается в этой среде**: что webview отрисуется в настоящем редакторе и что
  `showOpenDialog` вернёт папку — не проверено живьём.
- **Диалоги выбора папки в браузере** требуют жеста пользователя, которого встроенная панель дать
  не может: подменяется ровно handle, всё ниже — настоящее.
- **Нет проигрываемого медиа в репозитории** (WebM без кластеров, MP3 в один кадр).
- `text-json/toml/xml/yaml` не открываются в браузере — парсеры не собраны для worker; `jsonc` по
  той же причине не проверяет синтаксис.
- Пакеты `@modkitx-x3/*` не публикуются: «подключить» сегодня = workspace/git-ссылка.

## 5. Рабочие правила (выяснены дорогой ценой)

- Агент не запускает `pnpm check` одной командой на переднем плане: сторожевой таймер снимает его
  после 600 с молчания. Гейт запускается фазами.
- Больше двух параллельных агентов машина не тянет; упавшее под нагрузкой перепроверяется в
  одиночку, прежде чем ему верить.
- `dist-app` собирает Root после слияния. **Скриншот пользователя может прийти со сборки агента,
  сделанной до правки** — проверять фактом, а не спорить.
- `tsc -b` после `pnpm build` разваливает бандлы: строго `pnpm build` → `pnpm test`.
- Новый субпуть в `exports` требует записи в `PUBLISHED_ENTRIES` (`scripts/test/bundle.test.ts`),
  иначе `pnpm bundle` его прунит.
- Маркер поверхности в гейте сборки — строка её собственного кода, **не** имя part: словарь
  `parts.ts` едет в любой модуль, штампующий часть.
