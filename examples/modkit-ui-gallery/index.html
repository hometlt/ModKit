    Operation log

      Viewer window (MK2 layout)

      Header breadcrumb, view picker, filtered archive tree and collapsible property sections, assembled only from @modkitx-x3/ui primitives. The filter carries the MK2 toggles: match case, whole word, regular expression, plus glob.

      Subject card

      A unit owns no file — its card is assembled from data spread across many. The card is a list of section specs, not format-specific code: header, a custom command-card template, links, nested weapon cards and a stats table, all in the same collapsible chrome. Any subject, a file included, composes a different list and reuses the same renderer.

      Relations

      The relation graph as its own component: node-type buckets with counts, capped rendering on a canvas, and uses / used-by groups. Format-neutral — it takes nodes, edges and type buckets and knows nothing about units or upgrades.

      Card and graph log

        Asset viewers (MK2 parity)

        The panes the MK2 assets viewer had, rebuilt on the six existing data-source contracts. The image and audio stages take raw bytes from byte-range-source and hand them to the platform decoder, so they need no codec and no new contract.

        text-data formats

        Every independently installable text extension, opened through its own codec and syntax provider. The tabs switch between the semantic data source the codec publishes (tree or table), the text source, and the byte source — all three come from one session.

        Code editor

        The shipped text editor over the JSON sample. It never saves directly: every change goes through propose → plan → prepare → authorize → commit, and the log below records each host-owned step.

        Editor port log

          Image editing (MK2 texture-viewer parity)

          The MK2 tool set over a generated test texture: paint onto a scratch mask, blend into pixels, isolate a channel so a write touches one byte, select and crop. History is bounded at 100 patches. The surface owns pixels only — commit is wired by the host.

            Token inspector

            Live computed values for the current theme, read through readToken().
