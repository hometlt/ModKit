# `common/vector`

Vector-family reference extension. SVG is decoded as strict UTF-8, structurally scanned under the
host budget, and exposed as text plus a hierarchy. No SVG is executed or mounted into a live DOM;
active/external features are reported as unsupported security facts.

EMF and WMF now ship beside SVG in this product package and expose secure vector-scene
presentations. The older SVG staging route was retired in favour of the richer native
contribution. Historical decisions remain in inert `MIGRATION-NOTES-common-vector.json`.
