# `common/models`

Model-family reference extension. OBJ reuses the proven MK2 rules for vertices, groups, materials
and polygon triangulation. glTF validates the 2.x JSON document and indexes scenes, nodes, meshes,
materials, textures and animations. Both project only current MK3 contracts: metadata, hierarchy,
text and bytes. External material/buffer resolution and render-model construction remain explicit
unsupported features, not hidden eager dependencies.
