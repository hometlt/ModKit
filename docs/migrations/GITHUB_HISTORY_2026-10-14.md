# Публикация истории Core в hometlt/ModKit

С 14 октября 2026 года основной репозиторий Core —
https://github.com/hometlt/ModKit, ветка `main`. Локальный рабочий Core отслеживает
`origin/main`; публикация и последующие обновления выполнены без force-push.

## Почему изменились SHA

В исходной истории находились четыре версии двух собранных JSON-бандлов размером
около 150–157 МБ. Они превышали обычный GitHub file limit и были перенесены в Git LFS.
Изменились представление этих файлов в Git и SHA затронутых коммитов/потомков;
это не удаление истории исходников. LFS-полезная нагрузка загружена отдельно.
Для получения этих исторических бандлов нужен Git LFS.

Точка исходной миграции содержала **2630 коммитов**, включая обновление specs pin.
[CSV соответствий](history-sha-map-2026-10-14.csv) содержит **1792 изменившиеся пары SHA**,
а не 2630 строк. Остальные 838 коммитов этой точки не требовали замены SHA.
CSV сохранён побайтово: без заголовка, первая колонка — исходный SHA,
вторая — опубликованный. SHA-256 файла:
`18587e6441c31b2fcf7b9bd2db985e4712ecfc6e0daed7610f704260f4291e7d`.

После поиска исходного SHA в первой колонке используйте второй SHA с обычными
`git show`/`git log`. Отсутствие строки само по себе не доказывает удаление коммита:
неизменившиеся SHA и последующие коммиты не входят в эту первоначальную таблицу.

Исходный GitHub README-коммит `5b755edc6784c2a17243174cb7432143f8bed01f`
сохранён вторым родителем merge-коммита
`5cccf4d7b7b26a4abf10724b00dccb9fcb0c5905`. После него `main` продолжает развиваться;
историческая точка публикации не является текущим release pin.

## Границы сохранности и приёмки

Оригинальный граф дополнительно сохранён владельцем в проверенных приватных Git bundles
и локальных `archive-pre-github-*` tags. Эти tags/bundles не публиковать: они содержат
исходные pre-LFS большие blobs. Публичный GitHub не обещает доступность изменившихся
оригинальных SHA-объектов; для них служат приватный архив и таблицы соответствий.
Незакоммиченные рабочие файлы не включались в публикацию и при cutover сохранены побайтово.

Миграция Git-истории не означает успешную продуктовую приёмку. Release inputs фиксируются
отдельными SHA Core/расширений/Runtime; упаковка VSIX, подпись каталога, installed acceptance,
native fidelity и gameplay проверяются независимо.
