# Установка локального Modkit MK3 RC

Этот RC предназначен для локальной проверки и не является публичным выпуском.

1. Получите папку RC, публичный Ed25519-ключ автора сборки и установите Node.js 22 с pnpm 10 или новее.
2. Проверьте и установите подписанный RC в новую локальную папку:
   `pnpm release:install -- --out <RC> --target <INSTALL-STORE> --public-key <PUBLIC-KEY>`.
3. Активная неизменяемая версия находится по пути `root` из ответа команды; запускайте нужное
   приложение по его инструкции из этой папки.
4. Для обновления повторите шаг 2 с новой папкой RC и тем же `INSTALL-STORE`.
5. Для возврата к прошлой версии выполните
   `pnpm release:rollback -- --target <INSTALL-STORE>`.

Установщик сначала проверяет подпись, контрольные суммы, размеры и безопасные пути каждого файла,
а затем переключает активную версию. Старые версии не удаляются автоматически.
