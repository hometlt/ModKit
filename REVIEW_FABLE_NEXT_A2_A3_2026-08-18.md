## 6. Recommended first implementation slice (Fable)

**NXT‑105 «Capability‑RPC core v1» — одна ограниченная задача.**

- Состав: (a) protocol v1: envelope `{domain, version, session, generation, id}` и кадры `load` /
  `ready` / `call` / `return` / `throw` / `cancel` / `next` / `done` / `subscribe` / `event` /
  `unsubscribe` / `progress` / `release` / `terminate` с exact‑key валидаторами и лимитами;
  (b) handle table: owner/session/generation, `Lease` идемпотентность, invalidation on exit,
  cross‑generation отказ; (c) method‑surface registry: стандартные data‑source surfaces + правило для
  foreign (по D‑7), с `kind: value` / `lease` / `iterable` / `events`; (d) сериализация ошибок
  `ModkitError` ↔ DTO, `OperationCancelledError` как отдельный исход; (e) hostile‑suite §5.
- Не входит: транспорты (Node/Web), backend registry/SPI, `openSubject`, `apps/**`, public SDK ABI
  (кроме D‑7 при явном решении).
- Прием: `pnpm check` зелёный; hostile‑suite поимённо; Electron IPC (root) может заменить
  `DATA_SOURCE_METHODS`/handles на core без потери тестов `subject-services`.

Это совпадает с предложением Sol и закрывает F‑01/F‑02/F‑12 одним seam, не трогая его файлы.
