# PlayStation codecs

Product-owned PlayStation container codecs. The XA codec exposes validated CD-XA sectors, while
the CUE/BIN codec asks the host for the exact BIN companion and exposes bounded tracks, namespaces,
and byte ranges without resolving filesystem paths inside portable code.

The supported subsets remain explicit in their contribution manifests. Historical conversion
decisions remain in inert migration notes and preserve their original MK2 source paths.
